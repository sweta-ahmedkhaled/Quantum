Shor(9) encoding (concept)



Shor code is a concatenation:

- Phase protection (outer repetition in X basis): spread logical info across 3 blocks (leaders 0,3,6) then apply H.
- Bit protection (inner repetition in Z basis): within each block, copy leader into 2 more qubits.

Encoding steps (data qubits q0...q8):
1) CNOT q0→q3 and q0→q6
2) H on q0,q3,q6
3) For each leader b in {0,3,6}: CNOT b→(b+1), CNOT b→(b+2)
In [2]:
def shor_encode(qc, q):
    # Outer repetition to block leaders
    qc.cx(q[0], q[3])
    qc.cx(q[0], q[6])

    # Move leaders to Hadamard basis (phase protection layer)
    qc.h(q[0]); qc.h(q[3]); qc.h(q[6])

    # Inner repetition in each block (bit protection layer)
    for b in [0, 3, 6]:
        qc.cx(q[b], q[b+1])
        qc.cx(q[b], q[b+2])

def shor_decode_inverse(qc, q):
    # Undo inner repetition
    for b in [0, 3, 6]:
        qc.cx(q[b], q[b+2])
        qc.cx(q[b], q[b+1])

    # Undo Hadamards on leaders
    qc.h(q[0]); qc.h(q[3]); qc.h(q[6])

    # Undo outer repetition
    qc.cx(q[0], q[6])
    qc.cx(q[0], q[3])
 

Bit-flip correction inside each 3-qubit block



For block (b, b+1, b+2) we measure stabilizers:
- s1 = Z_b Z_(b+1)
- s2 = Z_b Z_(b+2)

Syndrome table (where 1 means “odd parity / −1 eigenvalue”):
- 00 → no X error
- 11 → X on b
- 10 → X on (b+2)
- 01 → X on (b+1)

We will measure each ZZ using an ancilla:
- ancilla starts |0>
- CNOT(qi→a), CNOT(qj→a), measure ancilla

def measure_ZZ(qc, anc, qi, qj, cbit):
    """
    Measure Z_i Z_j using ancilla anc into classical bit cbit.
    """
    qc.reset(anc)
    qc.cx(qi, anc)
    qc.cx(qj, anc)
    qc.measure(anc, cbit)

def bitflip_correct_block(qc, q, anc0, anc1, c_synd, base):
    # s1 = Zb Z(b+1)
    measure_ZZ(qc, anc0, q[base], q[base+1], c_synd[0])
    # s2 = Zb Z(b+2)
    measure_ZZ(qc, anc1, q[base], q[base+2], c_synd[1])

    # value = s1 + 2*s2
    with qc.if_test((c_synd, 3)):   # 11
        qc.x(q[base])

    with qc.if_test((c_synd, 1)):   # 01
        qc.x(q[base+1])

    with qc.if_test((c_synd, 2)):   # 10
        qc.x(q[base+2])
 

Phase-flip correction across blocks (Shor stabilizers)



Shor phase syndromes are X-type stabilizers across 6 qubits:
- S1 = X0 X1 X2 X3 X4 X5
- S2 = X3 X4 X5 X6 X7 X8

To measure an X-type operator with a Z-parity circuit:
1) Apply H to each involved data qubit (X ↔ Z)
2) CNOT(data → ancilla) for all involved qubits
3) Measure ancilla
4) Apply H back to those data qubits

Syndrome interpretation (treat blocks like repetition code):
- 00 → no phase error
- 10 → phase error in block 0
- 11 → phase error in block 1
- 01 → phase error in block 2

We correct by applying Z to a representative qubit in that block (use block leader 0,3,6).

def measure_XXXXXX(qc, anc, qubits, cbit):
    """
    Measure X⊗...⊗X over 'qubits' using ancilla anc -> cbit.
    """
    qc.reset(anc)
    for qi in qubits:
        qc.h(qi)
    for qi in qubits:
        qc.cx(qi, anc)
    for qi in qubits:
        qc.h(qi)
    qc.measure(anc, cbit)

def phaseflip_correct_shor(qc, q, anc2, anc3, c_pf):
    measure_XXXXXX(qc, anc2, [q[i] for i in [0,1,2,3,4,5]], c_pf[0])
    measure_XXXXXX(qc, anc3, [q[i] for i in [3,4,5,6,7,8]], c_pf[1])

    # value = s1 + 2*s2
    with qc.if_test((c_pf, 2)):   # 10 → block 0
        qc.z(q[0])

    with qc.if_test((c_pf, 3)):   # 11 → block 1
        qc.z(q[3])

    with qc.if_test((c_pf, 1)):   # 01 → block 2
        qc.z(q[6])

def build_shor_syndrome_circuit(apply_X=True, apply_Z=True, do_decode=True):
    q = QuantumRegister(9, "q")
    a = QuantumRegister(4, "a")      # ancillas
    c_bf = ClassicalRegister(2, "c_bf")  # reused per block
    c_pf = ClassicalRegister(2, "c_pf")  # phase syndrome
    qc = QuantumCircuit(q, a, c_bf, c_pf)

    # 1) Prepare arbitrary input on logical qubit q0 (example: |+>)
    qc.h(q[0])

    # Save "before encoding" state (we'll do separately with Statevector if needed)
    qc.barrier()

    # 2) Encode
    shor_encode(qc, q)
    qc.barrier()

    # 3) Inject errors on first physical qubit (q0)
    if apply_X:
        qc.x(q[0])
    if apply_Z:
        qc.z(q[0])
    qc.barrier()

    # 4A) Bit-flip correction per block
    bitflip_correct_block(qc, q, a[0], a[1], c_bf, base=0)
    bitflip_correct_block(qc, q, a[0], a[1], c_bf, base=3)
    bitflip_correct_block(qc, q, a[0], a[1], c_bf, base=6)
    qc.barrier()

    # 4B) Phase-flip correction across blocks
    phaseflip_correct_shor(qc, q, a[2], a[3], c_pf)
    qc.barrier()

    # 4C) Decode back to 1 qubit (optional but great for verification)
    if do_decode:
        shor_decode_inverse(qc, q)

    return qc

from collections import Counter

def run_measurements(apply_X=True, apply_Z=True, shots=4096):
    base = build_shor_syndrome_circuit(apply_X=apply_X, apply_Z=apply_Z, do_decode=True)

    # Z-basis measurement of decoded qubit q0
    qcZ = base.copy()
    c_outZ = ClassicalRegister(1, "outZ")
    qcZ.add_register(c_outZ)
    qcZ.measure(qcZ.qregs[0][0], c_outZ[0])

    # X-basis measurement: apply H then measure
    qcX = base.copy()
    c_outX = ClassicalRegister(1, "outX")
    qcX.add_register(c_outX)
    qcX.h(qcX.qregs[0][0])
    qcX.measure(qcX.qregs[0][0], c_outX[0])

    resZ = backend.run(qcZ, shots=shots).result().get_counts()
    resX = backend.run(qcX, shots=shots).result().get_counts()
    return resZ, resX

resZ, resX = run_measurements(apply_X=True, apply_Z=True, shots=4096)

Conclusions for My self:-

- Shor(9) corrects any single-qubit Pauli error because it corrects X and Z separately.
- Bit-flip (X) syndromes are ZZ parities inside each 3-qubit repetition block.
- Phase-flip (Z) syndromes are X-type stabilizers across blocks (measured via H trick).
- Syndrome measurement extracts error information without learning the logical amplitudes.
- Correction is conditional on syndrome (classical control).
- Verification: |+> stays |+> ⇒ random in Z basis but deterministic in X basis.
